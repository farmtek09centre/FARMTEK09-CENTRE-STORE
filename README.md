# FARMTEK09-CENTRE-STORE
FARMTEK09 CENTRE is a fruit tree and seedling nursery in Lower Kabete, Nairobi. We grow and sell grafted seedlings — mango, avocado, lemon, tangerine, apple, grape, and several banana varieties — for farmers and home growers. Order by WhatsApp or our online store, pay via M-Pesa, and choose pickup at the nursery or delivery.
